## გადამოწმების წესი
ყველა წესის სტატუსია `CLINICAL_REVIEW_REQUIRED`. ექიმი `reports/clinical_review_sheet.csv`-ში თითოეულ წესზე წერს „დადასტურებულია“ ან „შესასწორებელია“ და, საჭიროებისას, შესწორებას. მხოლოდ დადასტურებული წესი გადადის პლატფორმის საჯარო ვერსიაში.

### რეცენზენტისთვის მნიშვნელოვანი შენიშვნები
- **T-score / Z-score** (OSTEOP): ინახება აბსოლუტური მნიშვნელობით (მაგ. 2.5 = −2.5); ეს `meaning_ka`-შიც წერია.
- **იზონიაზიდის კვირეული დოზა** (TB, 3HP რეჟიმი): ერთეული `mg/kg/dose` ნიშნავს ერთ კვირეულ დოზას.
- ზოგი წყარო ინსტიტუციური ან მეორადია (მაგ. Children's Minnesota, Stanford Children's, drugs.com), ან მისი გამოცემის წელი დაუზუსტებელია. ასეთ შემთხვევაში ეს `supports` ველშია აღნიშნული.
