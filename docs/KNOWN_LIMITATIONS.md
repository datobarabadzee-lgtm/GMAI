# ცნობილი შეზღუდვები (KNOWN_LIMITATIONS)

თარიღი: 2026-10-21. თითოეულს ახლავს მიზეზი და ის, ვის გადაწყვეტილებაზეა დამოკიდებული.

## A. კლინიკური

1. **კლინიკური ვალიდაცია არ ჩატარებულა.** ყველა ტესტი ინჟინერულია (სინთეზური შემთხვევები). პასუხების კლინიკური სისწორე, ზღვრები და რეფერენსული დიაპაზონები კვალიფიციურმა კლინიცისტმა უნდა დაამტკიცოს.
2. **ჩაშენებული ლაბორატორიული დიაპაზონები** მონიშნულია `builtin_unvalidated`. ლაბორატორიის საკუთარი დიაპაზონი ყოველთვის პრიორიტეტულია; 18 წლამდე ლაბორატორიის დიაპაზონის გარეშე ინტერპრეტაცია არ ხდება.
3. **Clinical Rules Master v1 (107 თემა / 5,464 წესი)** საჯარო ვერსიაში არ არის — წარმოებულია UpToDate 2022-დან (მესამე მხარის საავტორო უფლება). ხელმისაწვდომია მხოლოდ internal ვერსიაში, მფლობელის საკუთარი ასლიდან იმპორტის შემდეგ. სტატუსი: BLOCKED (ლიცენზია).
4. **clinical-v2 (51 თემა / 962 ერთეული)** საცნობარო მასალაა, არა ინტერაქტიული კურსი; შინაარსის კლინიკური ვალიდაცია არ ჩატარებულა.

## B. მედიკამენტები

1. ქართული სახელის ამოცნობა ≠ ქართული ინსტრუქცია. 29,591 MIS ერთეულიდან: 0 კურირებული, 2,050 იდენტური ინგლისური სახელით FDA-ში (კურაციის რიგი), 236 EMA-სთან, 24,074 მხოლოდ კატალოგი, 3,231 placeholder (`docs/MEDICATION_COVERAGE.md`).
2. კლინიკური ტექსტი პაკეტში არ არის; ინსტრუქცია ონლაინ იტვირთება FDA/EMA-დან. მათი შეფერხებისას ინსტრუქცია არ ჩანს (შეცდომა ცხადად ჩანს, ჩანაცვლება არ ხდება).
3. MIS snapshot-ში გაუქმების სტატუსი არ არის — გაუქმებული ქართული პროდუქტები ვერ გამოირჩევა.

## C. ძიება

1. ძიება ლექსიკურია (ტერმინები, ფუძეები, ქართულ-ინგლისური ლექსიკონი, hash n-gram). პერიფრაზის recall@5 — 63%, ყოფითი აღწერის — 63% (`docs/RETRIEVAL_EVAL.md`). ნასწავლი embedding ჩართული არ არის: ყოველ კითხვაზე ფასიანი გამოძახება — მფლობელის გადაწყვეტილება.
2. ქართული ტერმინი, რომელიც ლექსიკონში არ არის (მაგ. „ბრუცელოზი“), ინგლისურენოვან შიდა წესებს ვერ უკავშირდება → „არ არის დაფარული“ (არასწორი თემის ჩანაცვლების ნაცვლად).

## D. ინფრასტრუქტურა

2. ატვირთვა ≤ 4 MB ჯამში (Vercel-ის 4.5 MB request ლიმიტი). საკუთარ ჰოსტზე იზრდება `NEXT_PUBLIC_UPLOAD_MAX_TOTAL_MB`-ით მხოლოდ მაშინ, თუ proxy-ც იღებს.
3. ავთენტიფიკაცია: ოპერატორი (`OPERATOR_TOKEN`) და რეცენზენტები (`REVIEWERS`) token-ით. SSO/RBAC არ არის.
