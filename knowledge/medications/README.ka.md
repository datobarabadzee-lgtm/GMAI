# მცირე L5 პაკეტი მედიკამენტებისთვის

კლოდს მიეცი ეს საქაღალდე/ZIP და `CLAUDE_HANDOFF.md`.

მონაცემები დაახლოებით 27 MB-ია. FDA-ს ჩამონატვირთის ყველა 401,216 ჩანაწერის ID, არსებული სახელების კავშირები და MIS-ის ყველა 29,591 უნიკალური კატალოგური ჩანაწერი შენარჩუნებულია. სრული ინსტრუქციები ამ პატარა პაკეტში არ დევს: ისინი FDA-დან მოთხოვნისას იტვირთება. სრული ოფლაინ ვერსია ძველ არქივში რჩება.

მსოფლიოში/საქართველოში ყველა წამლის არსებობას ეს არ ადასტურებს. MIS-ის სრული ინსტრუქციები არ ჩამოტვირთულა; დაუდასტურებელი ქართულ-ინგლისური კავშირები ავტომატურად არ გამოიყენება. FDA-ს უსახელო ჩანაწერები მხოლოდ ID-ით რჩება.

პაკეტი ჯერ აპლიკაციაში არ არის ინტეგრირებული და მოდელი არ გაწვრთნილა. თან ახლავს server-only Node.js runtime, ტესტები და კლოდისთვის ინტეგრაციის დეტალური ინსტრუქცია.

ZIP-ის გახსნის შემდეგ `data/` შიგნით `.gz` ფაილები დამატებით არ გაშალო. სწორედ შეკუმშული ფაილები უნდა შეიტანო deploy-ში. `node test.mjs` მუშაობს ინტერნეტის გარეშე; `node live-test.mjs` ამოწმებს FDA-თან რეალურ კავშირს.
